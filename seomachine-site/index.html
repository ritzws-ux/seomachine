시작하기

로컬 환경에서 SEOMachine을 설치하고 첫 번째 글을 작성하는 방법을 안내합니다.

1

사전 요구사항

SEOMachine은 Claude Code CLI 위에서 동작합니다. 먼저 Claude Code가 설치되어 있어야 합니다.

# Node.js 18+ 필요
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
Claude Pro 또는 API 키가 필요합니다. claude.ai 구독이 있다면 바로 사용할 수 있습니다.
2

레포지토리 클론

SEOMachine을 로컬에 복사합니다.

git clone https://github.com/TheCraigHewitt/Seriously-Simple-SEO.git
cd Seriously-Simple-SEO
3

Python 의존성 설치

분석 파이프라인에 필요한 패키지를 설치합니다.

pip install -r data_sources/requirements.txt
4

컨텍스트 파일 설정

context/ 폴더의 파일들을 우리 비즈니스에 맞게 수정합니다. 이 파일들이 콘텐츠 품질의 핵심입니다.

# 필수로 수정해야 할 파일들
context/brand-voice.md # 브랜드 톤 & 메시지
context/style-guide.md # 문체, 포맷 규칙
context/features.md # 제품/서비스 설명
context/internal-links-map.md # 주요 페이지 링크
5

API 자격증명 설정 (선택)

GA4, GSC, DataForSEO, WordPress 연동이 필요한 경우 설정합니다. 글쓰기만 할 경우 이 단계는 건너뛰어도 됩니다.

# .env 파일 생성
cp data_sources/config/.env.example data_sources/config/.env

# .env 파일을 열어 API 키 입력
GA4_PROPERTY_ID=your_property_id
DATAFORSEO_LOGIN=your_login
DATAFORSEO_PASSWORD=your_password
WP_URL=https://yourblog.com
WP_USERNAME=your_username
WP_APP_PASSWORD=your_app_password
6

Claude Code 실행 & 첫 번째 글 작성

레포 루트에서 Claude Code를 실행한 다음 커맨드를 입력합니다.

# Claude Code 실행
claude

# Claude Code 안에서 커맨드 입력
/research 팀 협업 툴 비교
/write 팀 협업 툴 선택 가이드
/publish-draft drafts/팀-협업-툴-선택-가이드.md
처음 실행 시 Claude Code가 컨텍스트 파일들을 읽고 브랜드 스타일에 맞는 글을 생성합니다. 리서치 → 작성 → 발행 순서를 따르는 것을 권장합니다.

커맨드 레퍼런스

모든 커맨드는 Claude Code 안에서 /커맨드명 형태로 실행합니다.

콘텐츠 생성
/write [주제]
완성된 블로그 글 생성. SEO 최적화, 메타 태그, 내부 링크까지 자동 포함. 실행 후 SEO Optimizer, Meta Creator, Internal Linker 에이전트가 자동으로 후처리합니다.
→ drafts/ 에 저장
/article [주제]
간단한 글 작성. /write보다 가벼운 버전. 빠르게 초안이 필요할 때 사용합니다.
→ drafts/ 에 저장
/rewrite [주제]
기존 글 업데이트. 오래된 콘텐츠를 최신 정보로 갱신하고 SEO를 재최적화합니다.
→ rewrites/ 에 저장
/optimize [파일]
SEO 최종 다듬기. 키워드 밀도, 제목 구조, 메타 태그를 최종 점검합니다.
/repurpose [파일]
콘텐츠 채널별 재활용. 블로그 글을 LinkedIn, Medium, Reddit, Quora에 맞는 형태로 변환합니다.
→ repurposed/ 에 저장
리서치 & 분석
/research [주제]
키워드 & 경쟁사 리서치. 검색량, 경쟁도, 관련 키워드를 분석해 콘텐츠 브리프를 생성합니다.
→ research/ 에 저장
/research-serp
SERP 분석. 상위 10개 결과의 콘텐츠 구조, 길이, 패턴을 분석합니다.
/research-gaps
콘텐츠 갭 분석. 경쟁사가 다루고 있지만 우리가 없는 토픽을 찾아냅니다.
/research-trending
트렌딩 토픽 발굴. 지금 검색이 급증하는 키워드와 주제를 파악합니다.
/research-performance
성과 기반 리서치. GA4 + GSC 데이터로 개선 가능성이 높은 글을 찾아냅니다.
/research-ai-citations [주제]
AI 인용 감사. ChatGPT, Perplexity 등 AI 툴이 어떤 소스를 인용하는지 분석합니다.
/analyze-existing [URL]
기존 콘텐츠 건강 진단. URL이나 파일을 분석해 SEO 개선점을 제시합니다.
전략 & 기획
/cluster [주제]
토픽 클러스터 전략. 필러 페이지 + 서포팅 아티클 + 내부 링크맵을 포함한 완성된 클러스터 전략을 생성합니다.
/priorities
콘텐츠 우선순위 매트릭스. 검색량, 경쟁도, 비즈니스 임팩트를 기준으로 다음에 만들 콘텐츠를 결정합니다.
/performance-review
콘텐츠 성과 리뷰. 분석 데이터 기반으로 개선 우선순위가 높은 글을 찾고 액션 플랜을 제안합니다.
랜딩 페이지
/landing-research
랜딩 페이지 리서치. 타겟 키워드와 경쟁사 랜딩 페이지를 분석합니다.
/landing-write
랜딩 페이지 작성. CRO 베스트 프랙티스를 반영한 전환 최적화 랜딩 페이지를 생성합니다.
→ landing-pages/ 에 저장
/landing-audit
랜딩 페이지 감사. 기존 랜딩 페이지의 SEO와 전환율 개선점을 분석합니다.
/landing-competitor
경쟁사 랜딩 페이지 분석. 경쟁사의 구조, 메시지, CTA 전략을 분석합니다.
/landing-publish
랜딩 페이지 발행. WordPress에 랜딩 페이지를 발행합니다.
발행
/publish-draft [파일]
WordPress 발행. Yoast SEO 메타데이터 포함, REST API로 WordPress에 즉시 발행합니다. WordPress REST API + 커스텀 플러그인 필요.
